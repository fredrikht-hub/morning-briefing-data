# morning-briefing-data

Public JSON data feed for the [morning-briefing](https://github.com/fredrikht-hub/morning-briefing) tool.

This repository is automatically updated by a GitHub Actions workflow in the private
`morning-briefing` repo. It contains only generated JSON output — no source code.

- `latest.json` — the most recent briefing
- `briefing-YYYY-MM-DD.json` — dated archive of each day's briefing
